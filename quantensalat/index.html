  • Tippen auf etwas: Ansehen, Benutzen/Nehmen oder Reden.
  • Gegenstand antippen, dann auf etwas im Bild: benutzen. Oder auf einen zweiten Gegenstand: kombinieren.
  • Manche Gegenstände kann man direkt benutzen: antippen, dann ▶.
  • 🔍 zeigt alle interessanten Stellen, 💡 gibt einen Tipp.
  • Das Spiel speichert automatisch.
